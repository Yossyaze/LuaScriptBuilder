# LuaScriptBuilder

Hammerspoon 用の自動化スクリプトを、直感的な UI で構築・管理するためのツールです。

## 🚀 公開ページ
[https://luascriptbuilder.web.app](https://luascriptbuilder.web.app)

## 🛠 機能
- 各種自動化ステップ（キー入力、クリック、待機、条件分岐など）の構築
- Firebase によるプロジェクトの同期
- Hammerspoon 用 Lua スクリプトの生成

## 開発
このリポジトリへのプッシュは、GitHub Actions を通じて自動的に Firebase Hosting へデプロイされます。
